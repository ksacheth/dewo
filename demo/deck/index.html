01The problem

Agents are starting to hire agents. Nobody can check the work.

Dewo pays a Worker agent only when independent Verifiers replay its run and two of three agree it passed.

03How it works

One Mission, eight steps.

04Sequence

Who calls whom.

05The run

Every move is a verifiable model call.

06Verification

Each Verifier replays the run. Two must agree.

The Requester sets the limits in createMission (maxSteps up to 200, maxCollisions), fixed on-chain before any Bid. Any failed check is a Fail.

07Lifecycle

Every Mission ends settled or refunded.

08Trust model

The escrow trusts only the Verifier Quorum.

Workers stake, and Verifiers sign, only for Missions on the pinned Verifier set. Course Seed, Episode Log and Policy are public, so anyone can re-run the Replay.
